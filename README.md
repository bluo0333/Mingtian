# 明天 (Míngtiān)

Productivity companion focused on thought externalization and low friction task management.

Míngtiān combines structure with reflective workflows through  task breakdowns, brain dumps, focus sessions, and resurfaced ideas. All encapsulated within a mobile experience designed to help you feel calm and collected.

Built primarily as a personal use iOS application for a guy with a cluttered mind.

---

## Philosophy

Míngtiān focuses on:
- reducing cognitive clutter
- lowering activation energy
- helping users externalize thoughts
- maintaining continuity between ideas and action
- creating a calmer relationship with productivity

The goal is not to maximize output, but to support intentional progress.

---

## Core Features

### Brain Dump System
Quickly capture:
- thoughts
- reminders
- ideas
- ambitions
- unfinished intentions

The app later resurfaces selected thoughts contextually to encourage reflection and follow-through.

---

### AI-Assisted Task Breakdown
Using the Anthropic API, vague goals can be transformed into structured, actionable steps.

"Need to apply for internships"
